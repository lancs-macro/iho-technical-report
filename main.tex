\begin{tcolorbox}[enhanced, colback=iholight, colframe=ihoblue, boxrule=0pt,
                  leftrule=3pt, sharp corners, left=12pt, right=12pt,
                  top=10pt, bottom=10pt]
{\sffamily\large\bfseries\color{ihoblue}Abstract}\par\medskip
  The International Housing Observatory is a joint initiative of the Federal
  Reserve Bank of Dallas, Lancaster University and the University of Alicante,
  set up to monitor developments in international housing markets using a
  comparable cross-country database and a common set of econometric tools.
  This report documents the Dallas Fed International House Price Database
  (IHPD) and the monitoring methodology of the International Housing
  Observatory (\url{https://int.housing-observatory.com/}). It describes the
  database as currently released --- 26 economies and two aggregates,
  quarterly from 1975\,Q1 --- together with the construction methodology of
  \citet{mack2011}, to which this report is a companion rather than a
  replacement. It then documents how the data are accessed, and the three
  econometric tools the Observatory maintains: the Generalised Supremum
  Augmented Dickey--Fuller (GSADF) test used to detect and date-stamp
  episodes of exuberance \citep{phillips2015a, phillips2015b}, the PSY-IVX
  decomposition that separates fundamental from speculative movements in the
  price-to-rent ratio \citep{shi2021}, and a mixed-frequency dynamic factor
  model used to nowcast real house prices ahead of the official release.
  A final section records planned extensions to the database and the toolkit.
  This report is a living document updated alongside each data release; the
  version history is in Appendix~\ref{app:changelog}.
\end{tcolorbox}
