\begin{abstract}
  This report documents the Dallas Fed International House Price Database
  (IHPD) and the monitoring methodology of the International Housing
  Observatory (\url{https://int.housing-observatory.com/}). It covers data
  coverage (25 countries, quarterly from 1975\,Q1), variable construction,
  programmatic data access via the \texttt{ihpdr} \textsf{R} package, and
  the two econometric frameworks applied to detect and date-stamp housing
  market exuberance: the Generalised Supremum Augmented Dickey--Fuller
  (GSADF) test \citep{phillips2015a} and the PSY-IVX decomposition approach
  \citep{shi2021}. This report is a living document updated quarterly
  alongside each data release; the version history is in Appendix~\ref{app:changelog}.
\end{abstract}
