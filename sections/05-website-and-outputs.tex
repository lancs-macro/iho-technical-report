\section{Website and Outputs}
\label{sec:website}

\subsection{Main Platform}

The International Housing Observatory is publicly accessible at
\url{https://int.housing-observatory.com/}. The platform provides real-time
monitoring of housing market exuberance across 25 countries and is updated
quarterly following each new IHPD data release from the Dallas Fed.

\subsection{Interactive Dashboard}

The dashboard visualises:
\begin{itemize}
  \item BSADF sequences plotted against Monte Carlo critical values,
        by country and confidence level;
  \item shaded exuberance episodes overlaid on real house price and
        price-to-income series;
  \item cross-country heatmaps showing exuberance status by quarter.
\end{itemize}
Users can select individual countries, switch between the RHPI and RHPI/RPDI
indicators, and adjust the confidence level (95\,\%, 90\,\%, 80\,\%).

\subsection{Quarterly Monitoring Reports}

A PDF monitoring report is published each quarter following the IHPD data
release. Each report opens with a country-level exuberance summary showing,
for each of the 25 economies, whether the GSADF test rejects the unit-root
null at the 95\,\%, 90\,\%, or 80\,\% confidence level for the current
quarter, together with the BSADF date-stamp of the episode's start.

The core of each report is a set of BSADF sequence plots for both the real
house price index (RHPI) and the house-price-to-income ratio (RHPI/RPDI).
Each plot overlays the BSADF statistic on its Monte Carlo critical value
bands, shading the periods classified as explosive. These plots allow readers
to assess not only whether exuberance is currently detected but also how the
current episode compares in duration and intensity to historical ones.

Cross-country heatmaps provide a compact view of exuberance status across all
25 economies simultaneously, enabling the identification of synchronised
global episodes --- such as the early-2000s housing boom, the 2008--09
bust, and the 2020--22 pandemic-era surge. The commentary section contextualises
the current quarter's findings within these longer historical patterns and
flags any country-level developments of note.

Reports are published at \url{https://int.housing-observatory.com/} and
archived there by quarter.

\subsection{Companion Platform: Housing Fever}

The companion platform at \url{https://housing-fever.com/} applies the
PSY-IVX methodology of \citet{shi2021} (Section~\ref{subsec:psyivx}) to
decompose real house prices into fundamental and non-fundamental
(speculative) components. The fundamental component is estimated from the
long-run equilibrium relationship between the price-to-rent ratio and
economic drivers including interest rates, income, and the user cost of
capital, using the IVX estimator, which is robust to persistent and
explosive regressors. The non-fundamental residual is then subjected to
recursive right-tailed unit root tests to identify periods of speculative
excess.

This decomposition complements the GSADF-based analysis on the main
Observatory platform: while the GSADF test signals exuberance in raw or
inflation-adjusted price levels, the PSY-IVX approach distinguishes whether
that exuberance is driven by economic fundamentals or by speculative
dynamics that are decoupled from them. The platform is updated in line with
the quarterly IHPD release cycle.
