\section{Version History}
\label{app:changelog}

This report uses semantic versioning: \texttt{vMAJOR.MINOR.PATCH}.
\textsc{major} increments on structural changes or breaking schema changes;
\textsc{minor} increments on quarterly data updates or methodology additions;
\textsc{patch} increments on corrections or clarifications.

Each version is archived on Zenodo with a persistent DOI for citation purposes.
