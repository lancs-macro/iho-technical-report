\section{Website and Outputs}
\label{sec:website}

\subsection{Main Platform}

The International Housing Observatory is publicly accessible at
\url{https://int.housing-observatory.com/}. The platform provides real-time
monitoring of housing market exuberance across 25 countries and is updated
quarterly following each new IHPD data release from the Dallas Fed.

\subsection{Interactive Dashboard}

The dashboard visualises:
\begin{itemize}
  \item BSADF sequences plotted against Monte Carlo critical values,
        by country and confidence level;
  \item shaded exuberance episodes overlaid on real house price and
        price-to-income series;
  \item cross-country heatmaps showing exuberance status by quarter.
\end{itemize}
Users can select individual countries, switch between the RHPI and RHPI/RPDI
indicators, and adjust the confidence level (95\,\%, 90\,\%, 80\,\%).

The dashboard source code is maintained in the Observatory's private
repository.

\subsection{Companion Platform: Housing Fever}

The companion platform at \url{https://housing-fever.com/} applies the
PSY-IVX methodology (Section~\ref{subsec:psyivx}) to decompose house prices
into fundamental and non-fundamental components.
